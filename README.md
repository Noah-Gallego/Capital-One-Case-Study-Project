# Capital One Case Study Project

A case-study presentation and Python profit-calculation prototype for comparing credit-product assumptions.

## Overview

The repository contains:

- `Capital One Overview.pdf` — overview presentation.
- `Capital One Case Comp (1).pdf` — case competition material.
- `Proposed Solution for Business Problem .pdf` — proposed solution presentation.
- `calculator.py` — calculates and plots estimated profit for example $10,000 and $20,000 products.
- `index.html` and `assets/` — an exported presentation viewer.

The calculator models revenue from credit utilization, interest, annual fees, and bookings, then subtracts charge-offs, funding cost, and annual operating cost. It fetches a Capital One logo from an external URL when executed.

## Tech stack

- Python
- Matplotlib
- Exported HTML presentation assets

## Usage

Run `calculator.py` in an environment with its Python imports available and network access for the external logo request. It displays a profit chart rather than writing a result file.

Open `index.html` in a browser to view the included presentation export.
